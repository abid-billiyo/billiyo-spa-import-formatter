# Import Formatter for VS Code

A VS Code extension to automatically group, sort, and format your TypeScript/JavaScript imports.

## ✨ Features

- **Smart Grouping:** Organizes imports into logical categories (Next, React, MUI, API, Local, etc.).
- **Automatic Sorting:** Sorts imports alphabetically within groups.
- **Path Conversion:** Converts relative paths to absolute `src/` paths.
- **Type Splitting:** Separates type imports from value imports.
- **MUI Formatting:** Optimizes MUI component imports.

## 🚀 How to Use

1.  Open your TypeScript/JavaScript file.
2.  Run the command:
    - **Command Palette:** `Ctrl+Shift+P` (or `Cmd+Shift+P`), then search for `Organize Imports`.
    - **Shortcut:** `Alt+Shift+D` (Windows/Linux) or `Option+Shift+D` (macOS).

## 📦 Installation (Internal)

1.  Obtain the `import-formatter-X.X.X.vsix` file from your team.
2.  In VS Code Extensions view (`Ctrl+Shift+X`), click `...` (More Actions) -> "Install from VSIX...".
3.  Select the `.vsix` file and reload VS Code.
